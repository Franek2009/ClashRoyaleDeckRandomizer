# Interface screenshots

These captures show the static application after the R4 layout corrections,
with the approved project logo and the 123-card snapshot. Card artwork is loaded
from the configured Supercell hosts; displayed decks are real generated results.
No mockup is used as an interface background or screenshot replacement.

- `desktop-empty.png`, `desktop.png`: 1440px, initial state and generated deck.
- `mobile-empty.png`, `mobile.png`: 390px, initial state and generated deck;
  rules initially collapsed, card pool expanded.
- `responsive-320.png`, `responsive-768.png`, `responsive-1024.png`: generated
  deck, expanded rules and Card Pool page 5, showing middle-page pagination and
  Wild Slot labels at the regression widths.
- `logo-desktop.png` / `logo-mobile.png` mirror the current generated-deck captures.
- `../screenshot.png` mirrors the current desktop capture; historical versions
  remain available in Git history.

Captures use headless Chromium with system font fallbacks. Mobile width emulation
is not a physical-device test. Screenshot artwork remains subject to the existing
fan-content disclaimer and [asset provenance](../../static/assets/README.md).
