# v1.1.0

## Browser application

- The production application now runs statically on GitHub Pages. Deck generation
  runs in JavaScript with a local catalog; no application backend or API token is
  required to generate a deck. The previous Flask application remains in the
  repository for comparison and regression coverage.
- Configure three physical special slots: Evolution, Hero / Champion and Wild.
  Wild supports Off, Evolution or Hero / Champion; dual-form cards use the chosen
  active form. Generate exactly eight unique cards and open the ordered deck link.
- Constrain Available, Banned and Required cards, exact Spell/Building counts and
  average Elixir. Search the paginated catalog and apply rarity, cost, Evolution,
  Hero and Champion filters to generation. Mirror contributes 1 to the deck
  average; this does not describe its play cost.
- Lock cards in their slots when using Generate again. View deck analysis, recent
  history and favorites; export/import browser-local deck data as JSON.

## Interface

- Retro fan-site styling with warm panels, blue section bars, a compact fortress
  header, the author's approved logo and PNG favicon. Functional UI labels replace
  promotional copy; the active interface uses system fonts.
- Mobile rules and card-pool panels can collapse without losing their values.
  The generated deck uses four columns on compact screens. Keyboard focus, native
  form validation and touch targets are preserved.
- Pagination wraps at narrow widths, including 320px. Wild Slot labels have room
  at the 1024px desktop breakpoint; average-Elixir fields stack on the narrowest
  screens so their values remain readable.

## Correctness and robustness

- **R1:** reject invalid timestamps and impossible imported roles/forms. An invalid
  history entry or unavailable/full localStorage no longer prevents generation.
  Storage failures show a separate warning; failed operations do not claim success.
  Unreadable stored containers are preserved rather than automatically overwritten.
- **R2:** classify Heal Spirit as Troop in both models. Requiring it with one Spell
  now requires an additional actual Spell. The approved catalog contains 123 cards,
  including Minion Giant, Hero Ice Wizard/Electro Wizard and Evolution Elite
  Barbarians/Electro Giant. This is a bundled snapshot, not a live-data guarantee.
- **R3:** prune impossible cost/type branches with precomputed bounds and memoized
  failures. Difficult feasible configurations remain searchable; no production
  attempt/time limit replaces complete search. Independent brute-force comparisons
  and browser performance regressions cover these changes.

## Local catalog maintenance

- `--check` reads a systemd credential or manual environment fallback and writes a
  validated candidate with human-readable/JSON diffs outside the checkout. It never
  updates `cards.json` or pushes changes. Daily user-unit templates are provided.
- Optional `--sync` tests a candidate in an isolated clone and publishes only a
  cards-only commit after compatibility, test and remote-freshness checks.
  `--sync --dry-run` performs the checks without a commit/push. Notifications are
  optional and deduplicated; failures do not disable generation in the web app.
- Automatic publication requires separate owner setup and activation. It is not
  enabled by this release. Unknown mechanics/namespaces, removals and uncertain
  new Spell/Building classifications block publication. New Troop namespace IDs
  still rely on a documented heuristic.

## Distribution and limitations

- Releases test the static application and require the release commit to match
  current main and a successful live GitHub Pages deployment. The attached static
  ZIP contains `index.html`, `cards.json`, `static/`, `LICENSE` and a `COMMIT_SHA` marker;
  `SHA256SUMS` identifies the archive. GitHub's automatic source archives also
  include the retained development/Flask files.
- Card artwork loads from Supercell hosts. No arena, card-level or player-collection
  filters are included. History/favorites remain local to one browser. Deck links
  encode ordered IDs; active-form behavior inside the game is not guaranteed, and
  dual-form Wild cards may require a manual switch after import.
- Solver performance is regression-tested, not a universal runtime guarantee for
  every future catalog. Low-end physical phones are not covered by desktop mobile
  emulation. The logo source SVG still needs text outlines for portable use; the
  approved PNG is used in the interface.
